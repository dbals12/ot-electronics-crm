# T5-C — Hall 운영 대시보드

> 근거: `ADR-T5-00` 5장(T5-C — 핵심 축으로 격상), 9장(공수 확정)
> 선행조건: T5-0 완료(Trend_Flag__c 실데이터 필요), T5-A 있으면 더 좋음(모니터링 데이터)

## 목표 방향 (확정)

서정비·오도면이 12대 장비의 상태·Trend·변경이력·Case/RCA·예방 WO 진행률을 레코드 하나하나 클릭하지 않고, **장비 이미지와 개별 장비별 이상 추이 게이지**까지 포함해 한 화면에서 파악한다. 근거: Salesforce **Connected Assets / Asset Service Prediction / Asset Service Lifecycle Management(ASLM)**가 "IoT·정비이력을 통합한 자산의 실시간 통합 뷰 + 고장 전 예측"을 정식 제품으로 제공 — 이게 원래 사용자가 참고한 방향이고, Tableau Next는 그보다 낮은 우선순위의 대안이다(아래 경로 구분 참고).

## 구현 경로 (미확정 — org 확인 후 결정, 우선순위 순서 있음)

| | 경로 A1(1순위): Connected Assets / ASLM | 경로 A2(2순위): Tableau Next / Operations Dashboard | 경로 B(항상 가능): 표준 Report/Dashboard/List View 또는 커스텀 LWC |
|---|---|---|---|
| 상태 | ❌ PermissionSetLicense에서 안 보임(ADR 6.5장) — 단 PSL 조회가 이 제품군을 못 잡아낼 수도 있어 **Setup에서 직접 재검색 필요**(착수 시 최우선 확인 항목) | ✅ 라이선스 확인됨(Creator 20석·Consumer 10석) — 실제 구성 여부 미확인 | ✅ 항상 가능 |
| 우리 요구사항(이미지·게이지·자산 생애주기 뷰) 충족도 | 높음 — 제품 자체가 이 용도로 설계됨 | 중간 — 일반 KPI 대시보드라 이미지·게이지는 별도 구성 필요, 완전히 못 채울 수 있음 | 확실함 — 원하는 대로 만들 수 있지만 전부 직접 구현 |
| 채택 조건 | Setup에서 실제 확인되면 **최우선 채택** | A1이 없고, Tableau Next로 이미지·게이지 요구사항이 충분히 구성되면 채택 | A1·A2 둘 다 없거나 요구사항을 못 채우면 이걸로 확정 |

## 지금 당장 착수 가능한 것 — 순서대로 시도

1. **Setup에서 Connected Assets/ASLM 존재 여부부터 직접 검색**(경로 A1, PSL로는 못 봤을 수 있으니 재확인) — 있으면 최우선 채택
2. 없으면 **Tableau Next(경로 A2)**로 시도, 이미지·게이지 요구사항을 얼마나 채울 수 있는지 확인(공수 1~2일 추정)
3. 둘 다 안 되거나 요구사항(이미지+게이지)을 못 채우면 **경로 B(커스텀 LWC)**로 확정 착수(공수 3~4일) — **솔직히 말하면 이미지·게이지까지 원한다면 경로 B로 갈 가능성이 실제로 높다**

**이 순서를 건너뛰고 바로 LWC부터 만들지 않는다** — Plus-Alpha 최소주의 원칙(ADR 3장). 다만 요구사항(이미지+게이지)이 확정 조건이므로, 상위 경로가 이걸 못 채우면 지체 없이 경로 B로 넘어간다.

## 범위

- Hall A 12대 장비 상태 리스트(Trend_Flag__c 기준 색상 구분)
- **장비 이미지**(Asset에 연결된 Files/사진)
- **장비별 이상 추이 게이지**(현재값 대비 임계치 시각화) — 경로 A1/A2는 네이티브 위젯, 경로 B는 Salesforce 표준 Report의 **Gauge Chart**(라이선스 불필요, 플랫폼 기본 기능) 우선 시도, 그래도 12대 개별 표시가 안 되면 커스텀 LWC 게이지
- A-07 등 개별 Asset의 변경 이력(Rev.B 등)
- 연결된 Case/RCA
- 영향받은 동종 장비 목록
- 예방 Work Order 11건 진행률

## 비범위

- Hall 이외 확장(다른 Hall/사이트)
- 실시간 갱신(폴링/스트리밍) — 새로고침 기준으로 충분
- 모바일 전용 레이아웃(FSM은 T5-E가 별도 담당)

## 데이터 계약

**입력**: Asset, WorkOrderLineItem(Trend_Flag__c), Case, Problem(RCA), WorkOrder(예방 WO)
**출력**: 없음(조회 전용, 데이터 변경 안 함)

## 기존 T0~T4와의 관계

순수 조회 화면이라 기존 레코드/Flow에 쓰기 작업이 전혀 없음 — 회귀 위험이 구조적으로 낮음.

## 완료 조건 · QA

- 경로 A1/A2/B 중 어느 걸 시도했고 왜 그걸 채택했는지 문서에 기록됨(착수 기준 준수 확인)
- 12대 상태가 실제 `Trend_Flag__c` 값과 일치(쿼리 대조)
- **12대 각각 이미지가 표시됨**(육안 확인)
- **12대 각각 게이지(또는 동급 시각 위젯)로 이상 추이가 표시됨**(육안 확인 — 어떤 경로로 구현했든 이 결과는 필수)
- Feature Flag 없이도 화면 존재 자체는 무해(조회 전용이므로 별도 Off 스위치 불필요 — 필요시 Permission Set으로 노출 제어)
